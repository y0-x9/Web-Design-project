# ADU Smart Academic Advising System

CSC 307 Web Design and Programming project.

## How to Run

Open `index.html` in a web browser.

No server is required because this is a static HTML, CSS, and JavaScript website.

## Pages

- `index.html` - Home page
- `about.html` - About the system
- `study-plan.html` - Interactive class upload and tracking dashboard
- `course-details.html` - Course catalog and prerequisites
- `admin.html` - Admin page for adding, editing, and deleting courses in the browser database
- `tips.html` - Advising tips and media section
- `contact.html` - Contact and feedback form

## Requirement Checklist

- HTML5 structure across six connected pages
- CSS3 stylesheet with responsive layout and more than 20 visual properties
- JavaScript functions, events, if statements, loops, and local storage
- Form input and validation on the study plan and contact pages
- Tables on the study plan page
- Ordered and unordered lists on the about and tips pages
- Image asset on the home page
- Multimedia embed on the advising tips page
- Interactive course recommendations based on completed prerequisites
- Course database stored in browser local storage under `aduCoursesDb`
- Admin course creation, modification, deletion, and restore defaults through database functions
